- Complete directory reference: 12 top-level directories including hosts/, modules/, pkgs/, secrets/, openspec/, raw/.
- Naming conventions: nix modules in kebab-case (zsh-abbr.nix, docs-mcp.nix), docs in UPPERCASE (ARCHITECTURE.md, STRUCTURE.md), host directories lowercase (arch/), package directories kebab-case (nix-search-tv-fzf/).
- Module pattern: each group has a default.nix importing sub-modules; maximum 2 levels depth. Single-concern .nix files in modules/home/ for features, with grouped subdirectories dev-tools/ (CLI/language tools, mise) and agents/ (pi, hermes, docs-mcp, bifrost, agentmemory, tools).
- Home host composition: hosts/arch/home.nix imports ../../modules, enables programs (pi, bifrost, docsMcp, agentTools, agentmemory, hermes-agent, devTools, miseTools). modules/default.nix imports all home feature modules.
- Extension points: new packages in pkgs/<name>/default.nix → overlay in flake.nix; new feature modules in modules/home/<name>.nix → import in modules/default.nix; multi-file modules in modules/home/<group>/ with default.nix; new agents in modules/home/agents/<name>.nix → agents/default.nix; new hosts in hosts/<hostname>/home.nix → homeConfigurations in flake.nix; new secrets added to agents.yaml and declared in sops.nix; new systemd user services follow bifrost/docs-mcp/agentmemory pattern.
- Shell config: zsh via antidote (powerlevel10k, fzf-tab, zsh-vi-mode, eza, pay-respects), zsh-abbr for git/nix/file/systemd shortcuts. OpenCode symlinks: ~/.config/opencode → raw/opencode, ~/.agents → raw/agents via opencode.nix.
- Agentmemory: npm package, iii-engine in PATH, Hermes plugin deploys memory provider to ~/.hermes/plugins/agentmemory.
- Validation: no test suite; correctness checked via nh home switch or home-manager switch.
